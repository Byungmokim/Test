# NEXUS PRO — 업무 종합 대시보드 v2.0

> 고도화된 AI 기반 업무 관리 대시보드

## 🚀 주요 기능

| 기능 | 설명 |
|------|------|
| 🔐 로그인 시스템 | 이메일/Google 로그인, 관리자·팀장·팀원 역할 구분 |
| 👥 팀원 업무 분장 | 관리자·팀장 전용 업무 배분 및 공유 |
| 💬 업무 SNS 채팅 | 채널별 실시간 채팅, 팀원 현황 |
| 📌 포스트잇 보드 | 드래그앤드롭 가능한 가상 메모 보드 |
| 📊 결산 분석 | 일일/주간/월간/분기/연간 결산 |
| 📧 결산 메일 발송 | 일일 결산 자동 Google 메일 발송 |
| ⬛ 16:9 레이아웃 | 한 화면에 최적화된 대시보드 |
| 🌐 모든 기능 활성화 | 하단 상태바에서 온라인 확인 |

## 🛠️ Railway 배포

```bash
# 1. GitHub 리포지토리 연결
# 2. Railway New Project → Deploy from GitHub
# 3. 자동 감지: Node.js (npm start)
# 4. 배포 완료 후 URL 생성
```

## 💻 로컬 실행

```bash
npm install
npm start
# http://localhost:3000
```
